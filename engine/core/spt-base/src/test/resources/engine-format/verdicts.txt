# Size and duration values the engine accepts, and a few it refuses.
#
# Shared by two tests:
# - engine/core/spt-base/src/test/java/com/dell/spt/base/util/EngineFormatFixtureTest.java checks
#   every section against BinarySizeFormat.parseSize (item.data.size) and
#   TimeUtil.getTimeInSeconds (load.step.limit.time).
# - cli/internal/engineformat/engineformat_test.go checks that the CLI's pre-launch checks accept
#   every accepted row, so the CLI never refuses a value the engine accepts, and refuse every
#   *.refused row.
#
# Each row is a double-quoted string; \" and \\ are escaped, and \uXXXX is a UTF-16 code unit.
# Lines starting with # are comments. [name] starts a section.
#
# The *.enumerated and *.ascii sections are generated: every string the engine accepts of up to 5
# characters over the short grammar alphabet named in the test (*.enumerated), and of up to 3
# printable ASCII characters (*.ascii). Rerun the JUnit test with
# SPT_WRITE_ENGINE_FORMAT_FIXTURE=1 to rewrite them. The *.listed sections (accepted) and the
# *.refused sections (refused by the engine and by the CLI) are kept by hand.
